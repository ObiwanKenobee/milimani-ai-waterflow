# Milimani Fresh AI — Roadmap

README roadmap progress on the platform.

- [x] **Foundation** — Cloud database, auth (email + Google), RBAC roles, audit & auth event logs.
- [x] **Commerce MVP** — Catalogue, cart, checkout, mock payments (M-Pesa / card / invoice), order lifecycle, tracking, account settings.
- [x] **Operations MVP** — Production nodes, batch planning & lifecycle, quality test records gating release, inventory stock movements, operations console at `/operations`.
- [ ] **Traceability MVP** — Link batches to orders; customer-facing batch traceability records.
- [ ] **B2B portal** — Contracts, invoices, scheduled orders, multi-location management.
- [ ] **AI decision support** — Demand forecasts and recommendations with explainable inputs and human review.
- [ ] **WaterPod integration** — Ingest validated equipment and source telemetry.
- [ ] **Stewardship reporting** — Water, energy and packaging indicators with published methods.
- [ ] **Scale readiness** — Security review, resilience tests, compliance review, incident response.
